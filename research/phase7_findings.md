# Phase 7: held-out evaluation-to-target validation

Date: 2026-10-11. Independent seed split 100–119, not used in phases 1–6. All 960 runs were executed locally using Python 3.13, NumPy 2.3.5, SciPy 1.17.0. Source in experiments/phase7_heldout_targets.py, full output generated by the GitHub workflow. Local run CSVs available as conversation artifacts.

## Protocol
4 functions × 2 dimensions (2,5) × 2 transformations (identity/rotation) × 20 held-out seeds × 3 algorithms (Adaptive, Memory, GatedMemory) = 960 runs. Fixed maximum 240 objective calls per run. All algorithms start at the same x0 per matched instance. Target values: Sphere <=0.001; Ellipsoid <=1; Rastrigin <=5; Rosenbrock <=5. Targets were selected for this pilot and are not the standardized COCO target suite. Stop-at-first-target is recorded retrospectively from the objective wrapper; algorithms may continue after first hit, and the recorded hit count is the earliest observed evaluation.

## Results
| Function | Adaptive successes/80 | Memory successes/80 | Gated successes/80 |
|---|---:|---:|---:|
| Sphere | 80 | 80 | 80 |
| Ellipsoid | 50 | 53 | 52 |
| Rastrigin | 52 | 50 | 51 |
| Rosenbrock | 80 | 80 | 80 |
| Total | 262/320 | 263/320 | 263/320 |

Mean memory probes per run: Adaptive 0, Memory 29.665625, GatedMemory 2.24375. Gated reduces memory probes by 92.44% compared with Memory, but NOT overall function evaluations. GatedMemory has only one additional target hit versus Adaptive across 320 paired instances: no persuasive performance gain.

## Validity and novelty
This is a *negative/neutral* held-out result, not a new globally competitive optimizer. Target selection may favor easy regimes (Sphere and Rosenbrock are saturated). A robust paper requires COCO/BBOB targets, strong modern baselines (CMA-ES, MADS, BOBYQA, DE), multiple budgets, target-specific ERT/ECDF, confidence intervals and independent replication. Do not claim statistical significance, globally faster convergence, or theoretical novelty.
